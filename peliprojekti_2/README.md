# Rulettipeli

Tämä on yksinkertainen Pythonilla tehty rulettipeli.

Ohjelma kysyy pelaajan nimen ja iän. Pelaaja lisää rahaa pelitilille, ja yksi veto maksaa 2 euroa. Pelaaja voi veikata:

> numeroa 0–36
> punaista tai mustaa
> parillista tai paritonta numeroa

Lopuksi ohjelma arpoo ruletin tuloksen ja näyttää pelaajan valinnat.
